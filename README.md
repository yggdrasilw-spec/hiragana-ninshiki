# ひらがな認識・しりとり

手書きひらがな/カタカナ認識と、画像を使うしりとりアプリを含みます。

## 使い方

`index.html` または `shiritori.html` をHTTP(S)で開きます。モデルとTensorFlow.jsを読み込むためインターネット接続が必要です。

## データ・素材・クレジット

- 認識モデルは `tfjs_model/` に含まれます。画面には元モデルが64×64入力・71クラスだったことが表示されます。元モデルの作者、学習データ、利用条件は現時点で特定できていません。
- `shiritori.html` はWikipedia/Wikimedia Commonsの画像を実行時に取得し、作者・ライセンス情報を画面に表示する実装です。画像ごとの表示クレジットとリンクを確認してください。Wikimedia Commons: [利用条件](https://commons.wikimedia.org/wiki/Commons:Reusing_content_outside_Wikimedia)。
- 同梱音声: `hiragana.wav`, `katakana.wav`, `onsei001.wav`〜`onsei003.wav`。HTMLには素材提供元の表示が見当たらず、出典・利用条件は未確認です。
- TensorFlow.js 4.22.0をjsDelivrから読み込みます。GAS Webアプリにも接続する機能があります。接続・データの扱いはアプリ設定とサービス提供者の条件を確認してください。

## しりとりの連結演出・効果音

語尾と次の語頭の文字からロボットハンドが伸び、90度ひねってかみ合い、手のひらの押さえで隙間を締めます。手先だけの高速回転で固定した後、腕が3段階で縮んで次の単語を引き寄せます。通常約2.2秒。説明・読み上げと並行し、リセットでキャンセルできます。端末の「動きを減らす」設定では完成状態を表示します。音声OFFでは効果音も停止します。

効果音提供：**On-Jin ～音人～** — [サイト](https://on-jin.com/) / [利用規約](https://on-jin.com/kiyaku.php)。

使用した素材は「小さいモーター.mp3」「接続・連結.mp3」「meka_ge_moter02.mp3」「特殊攻撃02.mp3」です。ユーザー提供のMP3をアプリ向けに切り出し、再生速度・音量・フェードを調整し、連結演出コードへ埋め込んでいます。元MP3や素材ダウンロード機能は同梱していません。
