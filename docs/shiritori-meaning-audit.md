# 説明レビューの追加監査

初回全件レビュー後、Lunaの別担当が5担当の `reviewed` の変更済み説明から、レベルごとに等間隔で104語を抽出して確認した。各担当・レベルから7語ずつ、親担当のレベル3のみ対象が6語だった。全件の独立した再検証ではない。

確認項目は、1文目だけで概要が成立するか、レベル1の表現が平易か、語と説明が一致しているか、不要な細部を断定していないか。

- ID2304「コスモッグ」は「星雲ポケモン。」という分類名だけだったため、何の登場語かを1文目に、特徴を2文目にした。[公式紹介](https://www.pokemon.co.jp/ex/sun_moon/pokemon/161027_07.html)を根拠として `audit-overrides.json` に記録した。
- ID3「愛崎えみる」は層別サンプルとは別に確認した。元の中学1年生という誤りを、[東映の公式紹介](https://www.toei-anim.co.jp/tv/hugtto_precure/character/chara06.php)にある小学6年生に修正済みだった。
- サンプル内で、それ以外の明確な修正は確認されなかった。この結果を、全ての説明の正確さの保証としては扱わない。

親担当は別途、国や地域・歴史語・生物分類の疑義を公的資料や研究者の説明に照合し、`source-overrides.json` に記録した。

統合後の確認でID2375の表示名「コロモ」を衣の意味に取り違えた変更を検出した。読み「こもろ」、国旗検索、英名Comorosと[外務省の国別情報](https://www.mofa.go.jp/mofaj/area/comoros/data.html)を照合し、表示名を「コモロ」に直し、島国の説明に戻した。この1件だけを表示名変更の例外として統合処理と検査に明記した。

未解決の語は、[全件レビュー結果](shiritori-meaning-review.md)から追加確認の一覧を参照できる。
