# ロボット連結演出

採用モック: 2026-10-13。約2.2秒で「伸長→90度の向き合わせ→把持→押さえの締め付け→手先のみ3回転→ロック→3段引き寄せ」を表示する。左右の腕の軸をずらさない。音源と3D部品は shiritori-robot-link.js にまとめ、既存の単語カード間にマウントする。

- 初語・通常の履歴再描画では演出しない。同一ラウンドの同じ語数を重複再生しない。
- 説明・読み上げと並行し、完了まで次のCPU手番を進めない。リセット・再描画でキャンセルし、待機Promiseも解除する。
- 音は既存の ST.voice と連動。音声OFFは再生中の効果音も停止する。ブラウザの音声利用制限・音のデコード失敗はゲームを停止させない。
- prefers-reduced-motion では静止した完成状態を表示する。
- 完了文は実際の直前・現在の読みと、有効な接続文字を使用する。
