# 難しさで除外しない語彙拡充（2026-11-16）

「基本的に、不適切でなければ採用しましょう。難しくてもオーケーです。」という指定を採用方針v2として実装した。
専門語・稀語・古語・方言・別表記も採用対象にし、従来の一般語・生活系列から全名詞へ走査範囲を広げた。

前回公開した100,505項目・84,070読みに対し、18,984項目・新しい読み2,048種類を追加。
通常辞書は119,489項目・86,118読みになった。別表記・別語義を含む行数であり、異なる概念数とは別。
今回の内訳は関連表記17,344項目、構造を確認した複合語6項目、語義を独立照合したWordNet由来1,634項目。
古語等244項目・方言13項目には用法注記を付けた（これらの集計は重複しうる）。画像追加なし。

読み・表記の対応と説明の語義を照合できることは引き続き必要とする。旧仮名遣いを現代の読みとして扱わない。
下品・侮辱的など不適切な語義、取り違え、根拠不足は保留する。難しさ自体を保留理由にしない。
全件の専門家校閲や個別学年判定を済ませたものではなく、今回追加分は出典照合済み・暫定レベル4。

JMdict英語版3.6.2、日本語WordNet2.1と英語WordNetの対応を用いた。
英語対応を使う場合は当該JMdict項目の当該語義に結びつく証拠を記録し、複数語義がある英語だけで対応を推測しない。
公開前に10項目の語義対応違いを取り下げ、修正台帳に残した。バゲットは正しいパンの説明で再採用した。
以前の公開済み100,505行はそのまま保持した。

出典・ライセンスは既存の `data/general10000/source-metadata.json` と各LICENSE、各追加項目の記録を参照。
WordNet由来の説明と独自編集の説明を区別して保存している。

継続コマンドは `python -B -X utf8 scripts/expand-shiritori-lexicon.py --apply`。
採用した候補を新たな起点として関連表記・複合語・語義対応を走査し、現在の出典と基準で採用できるものがなくなるまで繰り返す。
これは辞書全体の網羅を意味せず、保留候補と未照合分は再開用の台帳に残る。

検証は出典証拠、採用方針、差分保持、取込履歴・再取込、学年台帳、配信整合とブラウザ表示で行う。
出典証拠テストは今回までの関連語26,838項目と個別編集397項目を対象とする。
公開時の実データ照合結果は `qa-output/lexical-expansion/public-policy2-verification.json` に保存する。
