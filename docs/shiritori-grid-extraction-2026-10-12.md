# 16語シートの機械検証と画像補完（2026-10-12）

52語へ画像を登録した。新規画像42枚（16語シート2枚から32枚、方式変更前に開始した単独画像6枚、コード生成図4枚）と、語義を照合した画像共有10語。辞書は6,521行を維持し、保存画像あり2,679行、未掲載3,842行、レベル1の未掲載1,085行。コミット・プッシュはこの作業では実施していない。

## 生成するシートの条件

今後の生成は16語を1枚の4×4シートにまとめる。外周も含め縦5本・横5本の連続したマゼンタ（#ff00ff）の罫線を要求する。イラストにはマゼンタを使わない。絵はコマの中で大きく使ってよい。大きな余白や中央50%への縮小は要求しない。文字・番号・ラベルは画像へ描かず、IDとコマ順は計画ファイルに保存する。

生成指示だけでは寸法条件を保証できないため、必ず実画像を機械検証する。語義と絵の内容の確認は別工程。切り出し座標は目視では指定しない。

## 切り出しの合格条件

`scripts/crop-shiritori-grid.py` が罫線の実測位置を使う。従来の等分座標・一定率の余白削除へのフォールバックは行わない。

- 強いマゼンタの画素が線の長さの94%以上を占める線を、縦横それぞれ5本検出する。
- 想定位置からのずれは全体の2.5%以内、線幅は2px以上・全体の2.5%以内。外枠は端から2px以内。
- 薄いマゼンタのアンチエイリアスも測定し、絵を削らず罫線とその縁を取り除く。
- 同じ方向のコマ寸法の最大／最小比は1.10以内。
- コマ内部に強いマゼンタが残っていない。
- 境界付近に残った薄い罫線色も検出・除去する。周囲5%の白以外の画素率は診断値のみで、合否条件にしない。絵が境界に近いことだけで再生成しない。
- 空コマを拒否する。白以外の画素率は1%以上。大きな絵や背景がコマを埋めてもよい。
- 16コマ全部が合格してから全画像を書き出す。縦横比を保ち、白い余白を付けて256×256へ収める。
- 既存ファイルや既存検証記録を上書きしない。

新規の2026-10-12以降のシート画像登録には `cropValidation` 記録が必要。既存登録の再実行は追加0枚。単独画像・コード生成図は元ファイル名に `single-` / `diagram-` を含めて区別し、全画面の縮小または正確な図の生成として記録する。

登録時には元シートから同じ検証を再実行し、原画像のSHA-256、実測罫線、切り出し座標、コマ順、全16枚の再生成PNGのSHA-256を照合する。ファイル名は `wave6-word-606.png` のように現在の語IDを含め、登録先IDとの取り違えも拒否する。辞書登録前に全バッチを検証する。

この検証は罫線・混入・端の切れ・出力の取り違えを検出する。元シートのコマの中に最初から別の絵が描かれている場合や語義の取り違え、イラストの構造自体の誤りを判定するものではない。その内容は `semantic-review.json` に記録した。

最新の既定方式は `magenta-grid-lines-only-v2`。大きな余白の制約を撤廃し、罫線のみを実測除去する。今回最初に登録した32枚の検証記録は旧 `magenta-grid-white-guard-v1` として保持し、再検証の互換性を維持する。今後の生成に旧方式の余白条件を要求しない。旧方式で余白不足として停止した実際の16語シートでも、新方式で全コマを切り出せることを確認した。

## 再現・確認

Python、Pillow、NumPyが必要。Windowsの既存監査スクリプトはUTF-8モードで実行する。

```powershell
python -B tests/shiritori-grid-crop.py
python -X utf8 scripts/audit-shiritori-image-coverage.py
node tests/shiritori-data.cjs
node tests/shiritori-import-history.cjs
python scripts/import-shiritori-assets.py data/batches/2026-10-12-wave6-images.csv
python scripts/build-shiritori-wave6-diagrams.py --output work/diagram-reproduction
```

32枚のシート画像を再検証するには、各 `crop-validation*.json` の `tiles[].file` を順番通りに拡張子なしでカンマ区切りにし、対応する原シートを指定する。`--verify-existing` は書き込みを行わない。

```powershell
python scripts/crop-shiritori-grid.py assets/shiritori/sheets/2026-10-12-wave6-marked-grid-a.png --names <16個のファイル名> --output assets/shiritori --report data/image-coverage/2026-10-12-wave6/crop-validation.json --verify-existing
```

`data/image-coverage/2026-10-12-wave6/` に全プロンプト、語義・ID・共有理由、切り出し検証記録、内容の確認記録、件数、未掲載単語一覧を保存した。原シートと単独原画像は `assets/shiritori/sheets/`、登録バッチは `data/batches/2026-10-12-wave6-images.csv`。追加52語はPC・スマホ、外部画像検索を停止したゲーム・画像確認画面で検証する。
