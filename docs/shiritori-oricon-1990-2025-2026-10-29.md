# 年間シングル資料からの音楽語彙追加

1990〜2025年の各年100枠を起点に、音楽作品・歌唱名義・主な歴代メンバーを追加した。

**2024〜2025年はオリコン公式の年間シングル1〜100位を照合した。1990〜2023年は公開された年間ヒット100曲の二次資料を使用しており、公式順位の完全照合は未完了。** 二次資料の掲載順をオリコン公式順位として保証しない。配信・ストリーミング・合算ランキングは対象に混ぜていない。

既存42,858行はバイト単位で保持し、42,859〜48,446番へ追記した。新しい読みは4,813種類。既存の人物・音楽作品に対応する40候補は既存IDを再利用した。メンバーは115グループの主な歴代所属を選んだもので、全在籍者の網羅ではない。

新規の意味は「はってん」レベル5、分野は「芸能・映画・番組」。人物や作品を知らない低学年向けCPU候補には加えない。画像はすべて `image_mode=none`。説明を独自に作成し、写真・ジャケット・歌詞・音源は保存しない。

複数年に載る同じ歌唱名義の同じ曲はまとめ、両A面は曲ごとに分けた。公式表に収録曲が併記されたシングル作品は、その作品名と収録曲名を区別して追加する。同名曲は説明で歌唱名義を特定する。

## 読み・人物の区別

- `1/2` は「にぶんのいち」、`1/3の純情な感情` は「さんぶんのいちのじゅんじょうなかんじょう」。
- `SixTONES` は「すとーんず」、`Doki it` は「どきっと」。
- 「永遠に」はゴスペラーズの曲を「とわに」、KinKi Kidsの曲を「えいえんに」として別々に登録した。
- `RYO` はORANGE RANGEとケツメイシで別人。`HIDE` と `hide` はGReeeeNとX JAPANで別人。
- `NAOTO` はORANGE RANGEの人物と、EXILE・三代目 J SOUL BROTHERSで活動した人物を分ける。同じ人物の所属は一つの説明にまとめる。
- 卒業・脱退・改名に伴う現在の在籍を断定せず「メンバーとして活動した人」と説明する。

日本語の形態素解析と英語音訳を読み作成の補助に使い、人名・特殊読み・数字題名を上書きした。最終的な読みは個別レビューJSONに固定する。読みの補助表は同じキーの重複を整理したもの。公式プロフィールの取得結果、氏名の本文掲載有無、歴代所属の編集判断は別々に記録している。

## 記録と検証

`data/dictionary-imports/2026-10-29-oricon1990-2025.*` に、取り込みCSV、個別レビュー、既存IDの再利用、3,600枠と登録IDの対応、出典、読み補助、歴代所属、検証結果を保存した。順位・売上を表示する機能は追加していない。

```sh
python -B -X utf8 scripts/import-shiritori-oricon.py
node tests/shiritori-oricon.cjs
node tests/shiritori-oricon-browser.cjs
node scripts/build-shiritori-delivery.cjs --check
node tests/shiritori-delivery.cjs
node tests/shiritori-import-quality.cjs
node tests/shiritori-import-history.cjs
```

全5,588意味の登録・学年・画像なし設定・ジャンル・配信を検証した。配信全48,446意味と120集計条件も検証した。PC 1280pxとスマートフォン390pxでは、それぞれ24例の詳細表示、長い曲名の折り返し、同音異義語4読みの全件切り替え、5語の入力、ん終わりの終了判定、画像の外部検索が発生しないことを確認した。

追記後の辞書は45,428読み、396分割ファイル。各ファイルは最大128読み。既存の地名・駅名追加辞書との版対応も再生成した。
