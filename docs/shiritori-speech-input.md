# 設定から使う音声入力

入口は「せってい」→「文字入力」→「にゅうりょくのしかた」→「おんせい（補助）」のみ。表紙とゲームの通常入力タブには追加しない。文字に親しむ目的を保つため、かなを大きく表示し、手書き・ボタン・キーボードと併用する補助入力として説明する。

## 対話

1. 選択すると音をオンにし、ゲーム画面で案内を読み上げて聞き取りを開始する。初回はブラウザのマイク許可が必要。
2. 日本語の確定認識を待つ。カタカナはひらがなに、漢字などは登録語の表記・読みデータから変換する。通常起動では読みデータを取得せず、漢字などが初めて返ったときに取得する。
3. 「○○ と認識。よければ オーケー、ちがえば ちがうよ」と読み上げ、画面にも選択中のかな種で表示する。
4. 「オーケー／OK／はい」で既存の語の検証・接続に進む。「ちがうよ／違うよ／いいえ」では入力を消し、「もういちど、しゃべってください」と案内する。それ以外の返答では確定しない。
5. CPUと説明の読み上げが終わったら、次の頭文字を案内して自動的に聞き取りを再開する。語の重複や頭文字違いは読み上げて再入力に戻る。読みの候補をタップで選ぶ従来の補正パネルは、音声確認済みの語には使わない。
6. 終了後は「もういっかい／もう一回」で児童から新しいゲームを開始する。音声モードでは聞き取り時に終了ポップアップを閉じ、案内と停止ボタンを見える状態にする。

## 停止・復帰

- 「おやすみ／ストップ」または停止ボタンで休止する。休止からは表示中の再開ボタンを使う。
- 無音は2回案内して待ち直し、3回続いたら休止。認識イベントが来ない場合は20秒で停止する。
- マイク拒否、通信エラー、読み上げ失敗や15秒の停滞は表示して停止する。読み変換の取得失敗は確定せず、言い直しを案内し、次回に再取得できる。
- アプリの読み上げ中とCPU処理中は聞かない。読み上げ終了から450ms空ける。認識器は単発・確定結果のみを使用する。
- 設定、別の入力、ダイアログ、リセットでは古い認識・変換結果を無効化する。別画面・タブへ離れると休止し、戻っても自動復帰しない。
- 音オフ／音量0でも休止し、再開ボタンで音をオンに戻せる。
- 音声モードを保存せず、再読み込みでは手書きに戻す。複数人設定の入力記憶にも保存しない。複数人の受け渡しは既存の明示操作を維持する。

ブラウザの音声認識サービスを使い、アプリは録音を保存しない。音声がサービス提供元に送られる場合がある旨を入口に表示する。対応状況・認識精度・許可の動作は端末とブラウザに依存する。実際の学校端末で、児童の発話、スピーカーの回り込み、通信・マイク許可を確認する必要がある。

## 読みデータと更新

`data/shiritori-speech-spellings.json` は JMdict の漢字表記・読みから抽出した補完データ。2026-10-05版の `jmdict-simplified` JSONを利用。元データのSHA256、抽出規則、出典URLを同ファイルに記録する。かなの表記制約に従い、よく使う読みがある語ではそれを優先し、稀な表記・検索用表記を除外する。ゲームへの語彙追加は行わない。

`data/shiritori-speech-readings.json` は登録語の表記と上記補完データを合わせた配信用データ。複数の読みがある漢字は、しりとりの頭文字だけで推測しない。5候補以内かつ合計40文字以内なら番号付きで表示・読み上げ、「1番」「2番」などの声で読みを選び、通常の確認に進む。候補が多い場合は言い直しを求める。辞書外の漢字や文章全体のかな変換には対応せず、かなをつなげて言い直す案内をする。

James William BREEN / Electronic Dictionary Research and Development Group の [JMdict](https://www.edrdg.org/jmdict/j_jmdict.html) を使用。[利用条件](https://www.edrdg.org/edrdg/licence.html)。補完・配信用の派生読みデータは [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/)。語義・翻訳は使用しない。設定画面にも出典・ライセンスを表示する。

JMdict更新時（月次を目安）:

```powershell
python scripts/import-shiritori-speech-spellings.py <jmdict-simplifiedのJSONファイル>
node scripts/build-shiritori-speech-readings.cjs
```

`whitelist.csv` 更新時:

```powershell
node scripts/build-shiritori-speech-readings.cjs
node scripts/build-shiritori-speech-readings.cjs --check
```

## 検証

`node tests/shiritori-speech-browser.cjs` は模擬認識・模擬読み上げを使い、1280/390/320pxで確認する。入口の限定、通常起動の追加通信なし、暫定結果の無視、ひらがな変換とカタカナ表示、確認前の未確定、否定・不明返答、変換取得失敗・曖昧な読み、CPU後の再待機、頭文字違い、遅延結果、無音、許可拒否、非表示、音オフ、停止再開、終了再開、再読込、非対応ブラウザを対象とする。実音声の精度と実機のマイク動作は自動試験の対象外。

既存の `tests/shiritori-delivery-browser.cjs` と `tests/shiritori-multiplayer.cjs` も確認する。
