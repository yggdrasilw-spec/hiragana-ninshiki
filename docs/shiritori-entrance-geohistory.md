## 学習範囲と確認の限界

日本史は原始・古代国家、平安政治と土地制度、中世の政治・社会・交流、近世の統治と経済、幕末明治、近現代の政治・外交・社会、文化史・史料・学問を整理した。世界史は古代オリエント、ギリシア・ローマ、南アジア・東南アジア、東アジア、イスラーム・中央アジア、中世ヨーロッパ、近世大西洋世界、革命・国民国家・帝国主義、アジアの変動、二つの大戦、冷戦以降、文化史を扱う。地理は地図・GIS、地形、気候・植生・土壌、農林水産業、工業・資源・貿易、人口・都市・村落、民族・地域、環境・防災、世界の主要な自然地域を扱う。

これは**網羅に向けた拡充であり、大学受験完全網羅ではない**。全社の教科書索引・入試問題に登場する語との全件照合はまだ行っていない。地域史の細目、文化作品・人物、現代史、統計資料や地図の読解などには引き続き確認が必要。単語の収録だけで資料読解や論述の受験対策を満たすものでもない。

科目の範囲は[東京書籍の地理歴史シラバス](https://ten.tokyo-shoseki.co.jp/syllabus/shakai/)を参照。日本史・世界史は取得できた令和5年度版、地理は令和9年度版の資料を範囲確認に使った。説明文は独自に作成し、出版社・辞書の説明の一括転載はしていない。[出典と確認範囲](../data/entrance-geohistory/sources.json)で科目の範囲資料、特定用語の照合、JMdictの読み・表記の一致を分けて記録している。

一般語中心のローカルJMdict索引に読み・表記が一致したのは候補898語中22語。専門語の大半は編集確認であり、全語の外部辞書個別照合や専門家校閲が済んだとは扱わない。既存159語は読み・表記の照合による除外であり、既存説明の全件再校閲ではない。五四運動と五・四運動のような中黒の差も重複と扱う。賀茂真淵、公事方御定書、正長の土一揆などの読みは照合後に既存の正規表記へ揃えた。

## 管理・検索

巨大な追加CSVを管理画面代わりにせず、編集用JSONLと検索用SQLiteを分ける。

- `data/entrance-geohistory/entries.jsonl`：898語の安定ID・読み・表記・説明・分野・既存行ID・取り込み時判定。`add`は今回追加した語、`existing-form`は取り込み時に既存表記と照合できた語を指す。現在の未登録語数を示す状態ではない。
- `data/entrance-geohistory/catalog.sqlite3`：先行2,000項目と今回の対象を現在の辞書行へ対応させた、2,798語義の検索DB。DBは再生成可能な管理用ファイル。
- `data/entrance-geohistory/coverage.json`：41分類の実収録件数と辞書ハッシュ。分類数や収録率を、大学受験全体の網羅率とは扱わない。
- `data/dictionary-imports/2026-10-28-entrance-geohistory.*`：登録バッチ・意味ごとの編集記録・登録前後ハッシュ・検証記録。CSVは既存の登録ゲート用に生成したもの。

SQLiteはゲームにダウンロードさせない。ゲームは引き続き軽量索引と最大128読みの分割JSONを使い、日本の地名・駅名95,520意味は任意追加辞書として扱う。

検索例（プロジェクトのフォルダでPythonを実行）:

```python
import sqlite3
db = sqlite3.connect('data/entrance-geohistory/catalog.sqlite3')
for row in db.execute('''
    SELECT t.word, t.reading, t.meaning, p.topic
    FROM terms t JOIN topics p USING(csv_id)
    WHERE p.subject = ? AND p.topic LIKE ?
    ORDER BY t.reading
''', ('日本史', '%近世%')):
    print(row)
```

編集用原本を直した場合は登録済みバッチを書き換えず、訂正または新しい追加バッチとして履歴を残す。通常辞書を更新した後は `python -X utf8 scripts/build-shiritori-entrance-catalog.py` で検索DBと集計を再生成する。
