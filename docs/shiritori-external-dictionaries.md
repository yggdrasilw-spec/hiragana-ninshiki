# 外部辞書からの単語の取り込み

2026-10-11にJMdictから計414件の語義を追加した。初回104件に加え、候補全体を整理して310件を選別した。追加414件の内訳はレベル1が149件、レベル2が242件、レベル3が23件。読みは412種類（「ふくし」と「がっき」はそれぞれ異なる意味を採用）。既存6,191行を保持し、現在は6,605行。

今回の310件は、レベル1が104件、レベル2が199件、レベル3が7件。件数の目標は設けず、生活・学校・道具・交通・文化・自然の不足を優先した。「教室」「給食」「台所」「鏡」などを補い、専門語は身近な現象の理解に役立つ少数に絞った。

## 候補全体の整理

初回取り込み前の固定データを基点にすると、候補は13,915種類の読み、表記・語義を分けた行は27,414件。英語の一般語版の原辞書は22,644項目ある。これらは数える単位が異なる。

全候補を機械的に整理し、採用した414語義は個別に意味とレベルを編集した。残りは未レビュー、保留、禁止語規則による除外に分けて管理している。全13,915種類の説明を人手で確認済みという扱いにはしていない。

| 状態（読み単位） | 種類数 | 処理 |
|---|---:|---|
| 採用 | 412 | 採用した414語義だけをゲームへ追加 |
| 既存語と同一の辞書項目 | 271 | 別読み・同義・別義の確認まで保留 |
| 今回の採用語と同一の辞書項目 | 53 | 読み違いや表記違いで増やさず保留 |
| 一般的な読みの印がない | 1,763 | 優先せず、適性の確認まで保留 |
| 禁止語規則に一致 | 209 | ゲームへ追加しない |
| 個別に見送りを決定 | 23 | 理由を保存して保留 |
| その他の未レビュー候補 | 11,184 | 意味・適性・レベルの確認まで保留 |

「ウィンド／ウインド」のような英語由来の別名、「コンピュータ／コンピューター」の読み違い、ゴルフクラブや野球の投球法の細かな呼び名、米国の州の固有名詞などは今回優先しなかった。身近な呼び名として定着している「鏡」と「ミラー」では、まず「鏡」を採用した。「物差し」と「定規」は学校で両方使う名称として、それぞれの用途を説明して採用した。

「駄菓子屋」「写生」「惣菜」「土砂降り」「満月」「長方形」は、語義・レベルを検討したものの既存の禁止語規則に一致するため採用を保留し、その理由を残した。今回は禁止語規則を変更せず、実際のゲームで使える語だけを追加した。

採用記録の `accepted` 配列には採用したエントリーID・表記・語義番号・レベルを保存する。同じ読みの別の意味は、それぞれの確認を終えてから追加する。

## 出典とライセンス

JMdictはElectronic Dictionary Research and Development Group（EDRDG）の辞書。Jim Breenが始めたプロジェクトのデータを、[jmdict-simplified](https://github.com/scriptin/jmdict-simplified) の英語・一般語版から取得した。辞書日付は2026-10-05、変換形式は3.6.2。取得URL・アーカイブのSHA-256は [download.json](../data/external-dictionaries/jmdict/download.json) に記録。

原辞書と取り込んだ派生データ（抽出データ、レビュー記録、追加CSVとその説明）は [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/) に従って配布する。権利者の表示と [EDRDGの利用条件](https://www.edrdg.org/edrdg/licence.html) へのリンクをアプリの設定画面にも追加した。この記載は既存の別出典の語やコードのライセンスを変更するものではない。

読み・表記・名詞の意味を辞書で確認し、英語の説明を参考に日本語の説明を編集した。英語語義の自動翻訳や、一般語フラグからの自動レベル割り当てはしていない。

## 判定基準

| レベル | 語の選び方 | 説明の書き方 |
|---|---|---|
| 1（1・2年生） | 家庭・学校で接する具体的なもの、行動、場所を優先する | 今回は全件ひらがな。最初の文で何を指すかを説明し、必要なら身近な例を添える |
| 2（3〜6年生） | 理科・社会の学習語や、背景の補足が必要な生活語 | 概要から説明し、測定の基準・目的・具体例などを補足する |
| 3（制限なし） | 中学校以降の専門的な分類・仕組み・抽象的な関係を必要とする語 | 専門語でも概要から説明する。難しい説明にするためにレベルを上げない |

たとえば「井戸」は現代の低学年の生活で接する機会が少なく、地下水の説明も必要なためレベル2。「細胞」「電子」は構造と働きの理解が必要なためレベル3。「ふくし」は社会の生活支援を指す「福祉」が2、文法の品詞を指す「副詞」が3。

「大さじ」は身近な道具でも容量と単位の補足が必要なためレベル2。「教師」「食卓」「学級」は日常で使う呼び方より改まった語なのでレベル2とした。「がっき」は、具体的な音楽の道具を指す「楽器」が1、学校の一年を分ける期間を指す「学期」が2。「エネルギー」は小学校高学年の理科につながる語として2にし、ジュールなどの単位の説明は加えていない。

説明は見出し語の反復や「○○のこと」で終えず、種類、役割、形、使う場面などで説明する。「あさって」は「あしたの、つぎのひ。」、「まゆげ」は「めのすぐうえに、よこにならんではえている、け。」とした。

## 記録と再現

- [原辞書の抽出](../data/external-dictionaries/jmdict/source-extract.json)：採用語の原エントリーと語義、読み・表記の適用制限を保存。
- [編集レビュー](../data/external-dictionaries/jmdict/reviews.json)：採用するエントリーID、読み、表記、語義の番号、説明、レベル、判定理由を保存。
- [追加CSV](../data/batches/2026-10-11-jmdict.csv) と [出典照合記録](../data/batches/2026-10-11-jmdict.csv.review.json)：再生成可能な取り込みデータ。
- [全候補の一覧](../data/external-dictionaries/jmdict/candidate-inventory.jsonl) と [選別の集計](../data/external-dictionaries/jmdict/selection-summary.json)：固定基点に対する全13,915種類の処理状態を保存。
- [個別の見送り理由](../data/external-dictionaries/jmdict/selection-deferrals.json)：今回優先しない語とその理由を保存。

自然や専門語の説明には、必要に応じて一次資料も確認し、URLをレビュー記録の `sources` に保存した。たとえば深海の範囲は [JAMSTEC](https://www.jamstec.go.jp/godac/j/godac/kaiyou/deepsea.html)、快晴の基準は [気象庁](https://www.jma.go.jp/jma/kishou/know/yougo_hp/tenki.html)、液晶の性質は [シャープの技術資料](https://jp.sharp/products/lcd/tech/what_lcd.html) を確認した。`reviewed` は編集とレベルの確認済みを表す。すべての説明の細部を、独立した一次資料で検証したという意味ではない。

```sh
node scripts/prepare-shiritori-jmdict.cjs build \
  data/external-dictionaries/jmdict/source-extract.json \
  data/external-dictionaries/jmdict/reviews.json \
  data/batches/2026-10-11-jmdict.csv
node scripts/import-shiritori-words.cjs data/batches/2026-10-11-jmdict.csv
node tests/shiritori-jmdict.cjs
node tests/shiritori-data.cjs
node tests/shiritori-meaning-review.cjs
node tests/shiritori-meaning.cjs
```

既存の語義レビューIDは固定のsource.csvに属する。新しい語を挿入しても、過去のレビューを別の語へ適用しないよう、出典記録から追加分を分離して照合する。再適用スクリプトも追加語と現在の画像情報を保持する。

候補の全体集計を再現する場合は、download.jsonに記録した配布ファイルを展開し、その完全なJSONを使う。基点は採用の進行で変わらないsource.csvで固定する。

```sh
node scripts/prepare-shiritori-jmdict.cjs candidates \
  /tmp/jmdict/jmdict-eng-common-3.6.2.json /tmp/candidates.jsonl \
  data/meaning-review/source.csv
node scripts/inventory-shiritori-jmdict.cjs /tmp/jmdict/jmdict-eng-common-3.6.2.json
```

採用分の原エントリーだけを持つsource-extract.jsonは、説明・CSVの再生成に使う。全候補の集計には完全な原辞書を使い、取得したJSONのSHA-256と固定基点のSHA-256を集計に残す。

## 次回の取り込み・月次更新

1. [配布ページ](https://github.com/scriptin/jmdict-simplified/releases/latest) から最新の英語版を取得・展開し、辞書日付、版、配布URL、ハッシュを記録する。
2. `node scripts/prepare-shiritori-jmdict.cjs candidates 最新の辞書.json /tmp/candidates.jsonl` を実行する。既存の読み、名詞以外、古語などの不適切な用法、ひらがなに直せない読み、「ん」で終わる読みを候補から除く。出力の `level` は未設定、`status` は `pending` のまま。一般語の印は参考情報に留める。
3. 候補を1語義ずつ読み、子ども向けの説明とレベルの理由を編集する。同音異義語は別々に判定する。形・用途・場面によって説明し、見出し語の言い換えだけにしない。
4. 原エントリーの抽出とレビューを保存して `build` でCSVを作る。読み・表記・語義の適用制限、名詞かどうか、レベルと判定理由、レビュー済みの状態、反復だけの概要、CSV書式を検査する。今回のレベル1の説明は漢字も拒否する。
5. 既存の採用IDは月1回、最新辞書と抽出データの読み・表記・対象語義を比較する。語義の変更・消失・適用制限の変更があれば、説明とレベルを再レビューする。旧レビューを無条件に流用して上書きしない。
6. 検証したCSVを取り込み、上記のテストを実行する。未確認候補の一括投入はしない。画像はこの作業では追加していない。既存の画像検索・フォールバック処理を利用する。

この候補抽出は新しい読みを探すためのもの。既存の読みへの新しい意味の追加は、既存の意味との重複を別途確認する。辞書の一般語版を使うことも、抽出に通ることも、児童向けとしての承認にはならない。
